# devkit docs

What devkit gives a project and how to use it. The [README](../README.md) has the commands in short.
The docs are a [uwiki](https://github.com/hiqsol/uwiki) vault: `uwiki serve . --open` browses them.

- [Concepts](Concepts.md): the layers, who owns which file, the rules devkit keeps
- [Setup](Setup.md): devkit in a new project or in one with its own lint, the questions
- [Commands](Commands.md): what each `devkit` command and mise task does
- [Checks](Checks.md): each lint step, the files it takes, the hook and the on-demand checks
- [A project's own](Customizing.md): steps, rules, words, tools and tasks a project adds or changes
- [CI](CI.md): the GitHub workflow and the GitLab jobs
- [Releases](Releases.md): bump, release and install a Python package
- [Updating](Updating.md): devkit update, conflicts, notes on each release
- [Troubleshooting](Troubleshooting.md): what doctor reports and other surprises
- [Development](Development.md): the template, the command, the tests, releasing devkit
